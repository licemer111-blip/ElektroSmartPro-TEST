# 📝 История изменений и версионирование

## Обзор
Фича позволяет отслеживать все изменения в проекте и создавать версии-снапшоты с возможностью восстановления.

## Возможности

### ✨ Основные функции
- **История изменений** - каждое изменение позиции записывается с автором
- **Автоматические версии** - система создает версии при значительных изменениях
- **Ручные версии** - можно создать версию в любой момент с описанием
- **Восстановление** - можно восстановить проект из любой предыдущей версии
- **Сравнение** - видно что именно изменилось в каждой позиции

### 🎨 UI/UX
- **Компактная кнопка** - "История" на странице проекта
- **Модальное окно** - полный список версий и изменений
- **Визуальные индикаторы** - типы изменений (создано/обновлено/удалено)
- **Аватары авторов** - видно кто внес изменения

## Техническая реализация

### 📊 База данных
```sql
-- История изменений
CREATE TABLE project_item_history (
  id UUID PRIMARY KEY,
  project_item_id UUID NOT NULL,
  user_id UUID NOT NULL,
  action TEXT NOT NULL CHECK (action IN ('created', 'updated', 'deleted')),
  old_values TEXT,
  new_values TEXT,
  changed_fields TEXT[],
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Версии проекта
CREATE TABLE project_versions (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL,
  version_number INTEGER NOT NULL,
  name TEXT NOT NULL,
  description TEXT,
  is_manual BOOLEAN DEFAULT FALSE,
  total_items INTEGER DEFAULT 0,
  total_value NUMERIC DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Позиции в версиях
CREATE TABLE project_version_items (
  id UUID PRIMARY KEY,
  version_id UUID NOT NULL,
  project_item_id UUID NOT NULL,
  -- все поля позиции на момент версии
  ...
);
```

### 🔐 RLS политики
- **История** - видят все с доступом к проекту
- **Версии** - видят все с доступом к проекту
- **Восстановление** - только владелец или admin/kierownik

### 🔄 Автоматизация
- **Триггеры** на INSERT/UPDATE/DELETE для логирования
- **Авто-версии** при >10 изменений за час или раз в день
- **Функции** для создания и восстановления версий

## Использование

### Создание версии
1. Нажмите "История" на странице проекта
2. Нажмите "Создать версию"
3. Введите название и описание
4. Сохраните

### Восстановление версии
1. В истории найдите нужную версию
2. Нажмите меню (⋮) справа
3. Выберите "Приwróć tę wersję"
4. Подтвердите действие

### Просмотр изменений
1. В разделе "Ostatnie zmiany" видно:
   - Кто изменил
   - Что изменилось (поля)
   - Старые и новые значения
   - Время изменения
