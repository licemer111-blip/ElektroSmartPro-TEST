# 💬 Комментарии к позициям

## Обзор
Фича позволяет команде обсуждать конкретные позиции в проектах в реальном времени.

## Возможности

### ✨ Основные функции
- **Комментарии к позициям** - каждый элемент в смете может иметь обсуждение
- **Real-time обновления** - комментарии появляются мгновенно у всех участников
- **@упоминания** - уведомления конкретных членов команды
- **Статусы комментариев** - можно отметить как решенные
- **Права доступа** - автор может редактировать, админ/kierownik - все

### 🎨 UI/UX
- **Компактный режим** - иконка с счетчиком нерешенных комментариев
- **Всплывающее окно** - по клику открывается полный список комментариев
- **Визуальные индикаторы** - решенные комментарии подсвечиваются
- **Автocomplete для упоминаний** - при вводе @ показывается список команды

## Техническая реализация

### 📊 База данных
```sql
-- Таблица комментариев
CREATE TABLE item_comments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  project_item_id UUID NOT NULL REFERENCES project_items(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  content TEXT NOT NULL,
  resolved BOOLEAN DEFAULT FALSE,
  resolved_by UUID REFERENCES auth.users(id) ON DELETE SET NULL,
  resolved_at TIMESTAMPTZ,
  mentioned_user_ids UUID[] DEFAULT '{}',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 🔐 RLS политики
- **SELECT** - все с доступом к проекту
- **INSERT** - все с доступом к проекту  
- **UPDATE** - автор или admin/kierownik
- **DELETE** - автор или admin/kierownik

### 🔄 Real-time
- Подписка через `supabase.channel()`
- Автообновление при добавлении/изменении
- Уведомления через `pg_notify()`

## Интеграция

### В таблице проекта
```tsx
<TableCell className={`text-center ${singleCellBorderClass}`}>
  <ItemComments 
    projectItemId={item.id} 
    projectId={projectId}
    compact={true}
  />
</TableCell>
```

### Server Actions
- `getItemComments()` - получить комментарии
- `addItemComment()` - добавить комментарий
- `resolveComment()` - отметить как решенный
- `deleteComment()` - удалить комментарий

## Использование

1. Откройте проект
2. Найдите позицию для обсуждения
3. Нажмите на иконку 💬
4. Напишите комментарий, используйте @ для упоминаний
5. Отправьте или отметьте как решенное
